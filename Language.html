⌨️ How to Type French Accents (French Keyboard Rules)

The computer-based TCF Canada exam requires you to use standard French accents like é, è, à, ç, û. Since standard English/Indian QWERTY keyboards don't show these letters, you have two free options depending on how you plan to practice:

Option A: The "French Canadian" Keyboard Layout (Recommended for TCF)

You do not need a new physical keyboard. Go to your computer's settings, add "French (Canada)" as an input language, and toggle between English and French using Alt + Shift.

The Cheat Sheet:

  • To type é: Press the ? / key.
  • To type è: Press the ' " (apostrophe) key.
  • To type à: Press the \ | (backslash) key.
  • To type ç: Press the ] } (right bracket) key.

Option B: The "International US Keyboard" Trick (No new layout to memorize)

If learning a new layout feels tedious, add the "United States-International" keyboard in your system settings. This allows you to type standard English but add accent modifications easily:

  • ' (Apostrophe) + e = é
  • ` (Grave/tilde key) + e = è
  • ^ (Shift + 6) + e = ê
  • ' (Apostrophe) + c = ç
